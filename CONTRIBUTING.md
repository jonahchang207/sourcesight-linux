# Maintenance and permissions

Jonah Chang (`jonahchang207`) is the sole authorized maintainer of original
SourceSight material. External patches, pull requests, mods and derivative
development are not accepted without prior written permission.

The root LICENSE permits inspection and unmodified personal, noncommercial
builds. Separately licensed components and previously granted rights remain
exceptions.

Maintainer changes should include proportionate build/regression checks,
accurate release notes and dependency attribution. Never publish personal
profiles, credentials or logs.
